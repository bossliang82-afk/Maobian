# 毛边 (Deckle Edge) 🌿

> 一款悬浮在电脑桌面的轻量情绪便签，收集生活中那些裁剪下来的“毛边”。

---

## ✨ 核心特性

### 1. 桌面常驻与自启
- **无边框透明**：只有便签纸和小猫浮在桌面上，默认不置顶，不遮挡工作。
- **开机自启**：默认开机自动唤起，右上角提供自启开关（点击可随心开启/关闭）。
- **人本主义晚间轻提醒**：每晚 21:00 自动检查今日是否记录，若尚未记录，以系统微气泡轻声呼唤，不粗暴弹窗。
- **随手拖拽**：按住空白纸面可拖到屏幕任意角落；右上角微标支持最小化和退出。

### 2. 低负担记录
- **一句话日记**：限制 30 字内，无字数压力；支持随机刷新引导问题。
- **情绪贴纸**：提供 8 款日常心情签（平静、emo、放空等）；不想打字时，选个贴纸也能直接封存。

### 3. 互动桌宠「毛边」
- **待机小动作**：小猫趴在纸缘，带呼吸、眨眼、抖耳和摆尾动画。
- **点击互动**：戳小猫会弹气泡说话（“我叫毛边~~”等）；连续戳多次会炸毛生气。

### 4. 封存与告别
- **时间感知告别**：封存后根据系统时间（早晨、午间、深夜）弹出对应的问候与好梦祝愿。
- **收尾选择**：可选【留在桌面】继续挂载，或点【拜拜】退出程序。

### 5. AI 复盘导出
- **自由筛选**：支持导出近 7 天、近 30 天或自定义日期的记录。
- **一键喂给 AI**：复制出的内容自带预设 Prompt，粘贴给 ChatGPT/Claude 可直接生成短句共鸣、AI 白日梦分享和一张治愈插画。

### 6. 纯本地存储
- 数据全在本地，无需联网注册，无隐私外泄风险。

---

## 🛠️ 本地运行与开发

```bash
# 安装依赖
npm install

# 启动桌面小组件
npm start
```
